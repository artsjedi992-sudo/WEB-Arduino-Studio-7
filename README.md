# Arduino Studio 7 Web

Браузърна основа на Arduino Studio 7. Проектът е отделен от настолното C# приложение.

## Стартиране

1. Отворете GitHub Pages адреса на проекта (след активиране на Pages) или изтеглете ZIP.
2. За локално тестване отворете `index.html` в браузър. Някои браузъри ограничават IndexedDB при `file://`; при такъв случай използвайте обикновен статичен HTTP сървър.
3. Създавайте и редактирайте файлове от панела вляво. Проектът се записва в IndexedDB на браузъра.

## Какво работи в първата версия

- Интерфейс на български език.
- Редактор на Arduino/C++ текст с номера на редовете и табове.
- Отваряне на локални текстови файлове.
- Локално съхранение на проекта чрез IndexedDB.
- Избор на Uno, Nano и Mega като настройки на интерфейса.

## Какво все още НЕ е реализирано

- Истинска компилация с AVR-GCC / Arduino CLI.
- Генериране на HEX файл.
- Качване към платка и сериен монитор.

Тези команди показват ясно съобщение, вместо да симулират успешна работа. За компилация е необходим реален компилатор, портнат към WebAssembly или достъпна сървърна услуга. За директно качване е нужен браузър и операционна система с поддържан Serial API. Firefox 115 под Windows 7 не предоставя Web Serial API.

## Съвместимост

Използвани са стандартни HTML, CSS и JavaScript без задължителни CDN библиотеки. Това намалява зависимостите и позволява по-широка съвместимост, включително с по-стари браузъри. Функциите за IndexedDB зависят от настройките на браузъра.

## План за развитие

1. По-пълен редактор с подсветка на C/C++ и автодовършване.
2. Управление на папки и няколко файла в един Arduino проект.
3. Истински AVR компилатор за Uno/Nano/Mega.
4. Експорт на HEX.
5. Серийна комуникация и качване там, където браузърът го поддържа.
6. Автоматични тестове и GitHub Pages.

Кодът е коментиран на български, за да може да се поддържа и разширява поетапно.

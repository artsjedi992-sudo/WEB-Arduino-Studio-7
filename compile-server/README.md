# Arduino Studio 7 — компилационна услуга

Това е отделният сървър за **истинска компилация** с Arduino CLI. GitHub Pages хоства само HTML/CSS/JavaScript и не може да стартира AVR-GCC. Сървърът изпълнява компилацията и връща HEX/ELF към браузъра.

## Публикуване в Render

1. Влезте в Render с GitHub и изберете **New → Blueprint**.
2. Изберете хранилището `artsjedi992-sudo/WEB-Arduino-Studio-7`.
3. Render ще прочете `compile-server/render.yaml` и ще изгради Docker услугата. Първото изграждане е по-бавно, защото инсталира Arduino AVR Core и AVR компилатора.
4. След публикуване отворете адреса на услугата и добавете `/health`. Очакваният отговор е JSON с `"ok":true`.
5. Натиснете **Провери / Компилирай** в Arduino Studio 7. При първо стартиране поставете адреса на услугата (без `/health`), например `https://arduino-studio-7-compiler.onrender.com`.

Render Free услугите могат да заспиват при липса на трафик. Първата компилация след събуждане може да изчака стартирането на услугата.

## Поддържани платки в тази версия

- Arduino Uno — `arduino:avr:uno`
- Arduino Nano — `arduino:avr:nano`
- Arduino Mega 2560 — `arduino:avr:mega`
- Arduino Leonardo — `arduino:avr:leonardo`
- Arduino Micro — `arduino:avr:micro`

Компилацията връща истинския лог от Arduino CLI и HEX/ELF файлове. Не се изпълнява качване към платка. Качването е изключено умишлено.

## Важно

- Компилационната услуга обработва само изходните файлове, изпратени от браузъра; работната директория се изтрива след всяка компилация.
- Включени са ограничения за размер на заявката, брой файлове, безопасни пътища и време за компилация.
- За публично използване на услугата е препоръчително да се зададе конкретен домейн в `ALLOWED_ORIGINS`, а не wildcard.
- Тази услуга е първоначална AVR конфигурация. Добавяне на ESP32, SAMD и други платформи изисква отделни cores и toolchains.

# Arduino Studio 7 - локална компилация

Този помощник използва Arduino CLI, който вече е инсталиран на компютъра. Не изтегля второ копие на CLI и не изисква Render.

## Стартиране

1. Разархивирайте/клонирайте проекта.
2. Стартирайте `Start-LocalCompiler.bat`.
3. Ако Arduino CLI не бъде намерен автоматично, въведете пълния път до `arduino-cli.exe`.
4. Оставете черния прозорец отворен.
5. В Arduino Studio 7 Web натиснете „Провери / Компилирай“ и задайте адрес:
   `http://127.0.0.1:8765`

Проверка на посредника: отворете `http://127.0.0.1:8765/health`. Трябва да се покаже JSON с `"ok":true`.

## Изисквания и бележки

- Windows PowerShell 3.0 или по-нова версия и .NET Framework 4.5+.
- Arduino CLI трябва вече да е инсталиран, с нужните board cores и библиотеки.
- Компилацията е локална; няма качване към платката.
- Разрешен е само origin `https://artsjedi992-sudo.github.io`.
- Посредникът слуша само на `127.0.0.1:8765`.
- Ако портът е зает, затворете друга инстанция на помощника.
